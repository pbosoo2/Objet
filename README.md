# 마법 오브제 보관함

다크모드용 HTML 오브제를 한곳에서 관리하는 GitHub Pages 정적 사이트입니다.

## 파일 구성

- `index.html`: 오브제 목록과 미리보기, 개별 오브제 링크
- `objects.js`: 목록에 표시할 오브제 정보
- `magic-spellbook.html`: 공중에 떠 있는 마법서 최종본 (이전 이름: fixed-shadow-spellbook.html)

마법서는 이미지가 HTML에 포함되어 있어 별도 이미지 파일이나 설치 과정이 필요 없습니다.

## GitHub에 게시하기

1. ZIP을 압축 해제합니다.
2. 위 파일들을 GitHub 저장소 루트에 올립니다. `index.html`이 저장소 최상단에 있도록 해주세요.
3. 저장소의 Settings → Pages에서 배포 소스를 브랜치로 설정합니다. 일반적으로 `main` 브랜치의 `/ (root)`를 선택하고 저장합니다.
4. 배포가 완료되면 Pages 설정에 표시된 사이트 주소를 엽니다.

기존 GitHub Pages 사이트에 추가한다면 위 파일들을 `objects/` 같은 하위 폴더에 넣어도 됩니다. 이때 목록 주소는 기존 사이트 주소 뒤에 `/objects/`를 붙인 주소입니다. 기존 사이트의 `index.html`을 덮어쓰지 마세요.

## 노션에 넣기

목록에서 원하는 오브제의 ‘링크 복사’를 누릅니다. 개별 오브제 주소를 노션의 임베드 블록에 넣습니다. 목록 페이지 주소가 아니라 `magic-spellbook.html`로 끝나는 개별 주소를 사용하세요.

이 방식은 HTML 파일 첨부의 파일명 헤더 대신 웹 임베드를 사용합니다. 노션 자체의 호버 버튼 등은 오브제 HTML에서 숨길 수 없습니다.

## 새 오브제 추가하기

1. 새 HTML을 같은 폴더에 추가합니다. 예: `moon-window.html`.
2. `objects.js`의 배열에 다음 형식의 항목을 추가합니다. 앞선 항목과 쉼표로 구분하세요.

```js
{
  title: '달빛 창문',
  description: '달빛과 별이 머무는 작은 창문.',
  file: 'moon-window.html',
  category: '밤의 풍경'
}
```

아직 만들지 않은 오브제는 초기 목록에 포함하지 않았습니다. 현재 목록에는 마법서 최종본 하나가 있습니다.
